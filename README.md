# 🌐 Web Development

Welcome to my **Web Development Repository**! 🚀

This repository contains my web development practice work, HTML assignments, and mini-projects created while learning the fundamentals of web development.

My goal is to strengthen my frontend development skills through consistent practice and hands-on projects.

## 📚 Repository Contents

| File | Description |
|---|---|
| `Course Curriculum.html` | Demonstrates HTML headings, paragraphs, ordered lists, unordered lists, and nested lists. |
| `Global news.html` | A simple news website using HTML sections, navigation, images, video, and audio. |
| `pratical assignment1.html` | HTML practical assignment. |
| `registrationform.html` | Student registration form using HTML. |
| `time table.html` | College timetable created using HTML tables. |

## 🛠️ Technologies Used

- HTML5
- Visual Studio Code
- Git & GitHub

## 🎯 Learning Objectives

- Understand HTML document structure.
- Practice HTML tags and elements.
- Create forms and tables.
- Work with hyperlinks and multimedia.
- Develop a foundation for frontend development.

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/ayushsingh-labs/Web--Development.git
   ```

2. Open the downloaded folder in VS Code.
3. Open any `.html` file.
4. Run it using your browser or VS Code Live Server.
